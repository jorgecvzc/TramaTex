# Estudio Técnico: Alineación de Dashboards (Post-MVP)

Este documento define el estándar para todos los Dashboards del sistema TramaTex, asegurando que compartan una estructura visual, funcionalidades mínimas y un manejo por teclado consistente.

## 1. Dashboards Identificados

- **Global:** `apps/frontend/src/pages/Dashboard.vue`
- **Entidades:** `apps/frontend/src/pages/parties/PartyDashboard.vue`
- **Productos:** `apps/frontend/src/pages/products/ProductDashboard.vue`
- **Ventas:** `apps/frontend/src/pages/sales/SalesDashboard.vue`
- **Taller (MES):** (En desarrollo/Pendiente de revisión de archivo)

## 2. Funcionalidades Mínimas Comunes

Todos los dashboards deben implementar:

### 2.1 Cabecera Estandarizada
- Uso de `BasePageHeader` (o slot `#header` en `BaseDashboardPage`).
- Título claro y migas de pan (`breadcrumbs`).
- Botón de **Actualizar** (`refresh`) con indicador de carga (`loading state`).

### 2.2 Rejilla de KPIs (Stats)
- 4 KPIs principales en la parte superior.
- Cada KPI debe ser un enlace directo a un listado filtrado.
- Estilo visual consistente (Icono de color + Etiqueta + Valor).

### 2.3 Accesos Rápidos (Operaciones)
- Botones destacados para las tareas más frecuentes (ej: "Nuevo Pedido", "Nueva Entidad").
- Atajos de teclado visuales en estos botones (ej: `Alt+N`).

### 2.4 Listado de Actividad Reciente
- Tabla simplificada con los últimos 5 registros del módulo.
- Filas clickeables para navegación rápida al detalle.

## 3. Estándar de Manejo (Keyboard First)

Los dashboards deben ser totalmente operables sin ratón:

### 3.1 Atajos Globales de Dashboard
- `Alt + R`: Refrescar datos.
- `1, 2, 3, 4`: Saltar al KPI correspondiente.
- `Alt + [Letra]`: Acceso directo a operaciones (ej: `Alt+N` para Nuevo).

### 3.2 Navegación por Foco
- Orden de tabulación (`tabindex`) lógico: KPIs -> Accesos Rápidos -> Actividad Reciente.
- Uso de `focus-visible` para destacar el elemento activo.
- Soporte de flechas de dirección para moverse entre tarjetas de KPI.

## 4. Plan de Acción

1. **Refactor de `Dashboard.vue` (Global):** Es el único que no usa `BaseDashboardPage`. Debe migrarse para ganar consistencia.
2. **Normalización de CSS:** Extraer estilos comunes de KPIs y tarjetas a un nuevo archivo `_dashboards.css`.
3. **Implementación de Lógica de Teclado:** Crear un composable `useDashboardShortcuts`.
4. **Sustitución de Iconos:** Migrar de `Material Symbols` a `Lucide Icons` en todos los paneles.

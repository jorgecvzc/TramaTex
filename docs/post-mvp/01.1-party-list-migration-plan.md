# Plan de Migración: PartyList.vue (Navegación por Teclado)

Este documento detalla los pasos para migrar el componente `PartyList.vue` y su base `BaseCatalog.vue` para soportar navegación completa por teclado, según el [Estudio de Unificación UI/UX](./01-ui-ux-unification-study.md).

## 1. Objetivos

- Permitir la navegación entre filas usando las teclas `Flecha Arriba` y `Flecha Abajo`.
- Acceder al detalle de una entidad pulsando `Enter`.
- Mantener el foco visual claro en la fila seleccionada.
- No romper la funcionalidad de scroll natural del navegador.

## 2. Cambios en `BaseCatalog.vue`

La lógica principal residirá en el componente compartido para que todos los listados se beneficien.

### 2.1 Estado y Propiedades
- Añadir `selectedIndex` (ref) inicializado en `-1`.
- Añadir prop `active` (boolean) para saber si el catálogo debe capturar eventos (opcional si se usa foco de elemento).

### 2.2 Manejo de Eventos
Implementar un listener de `keydown` en el contenedor principal de la tabla o globalmente mientras el componente esté montado:

```typescript
function handleKeyDown(e: KeyboardEvent) {
  if (props.items.length === 0) return

  if (e.key === 'ArrowDown') {
    e.preventDefault()
    selectedIndex.value = (selectedIndex.value + 1) % props.items.length
    scrollToSelected()
  } else if (e.key === 'ArrowUp') {
    e.preventDefault()
    selectedIndex.value = (selectedIndex.value - 1 + props.items.length) % props.items.length
    scrollToSelected()
  } else if (e.key === 'Enter' && selectedIndex.value !== -1) {
    handleRowClick(props.items[selectedIndex.value])
  }
}
```

### 2.3 Visualización
- Aplicar clase `.is-keyboard-selected` a la fila cuyo índice coincida con `selectedIndex`.
- Estilo en CSS:
```css
.row-clickable.is-keyboard-selected {
  background-color: var(--color-background-soft);
  outline: 2px solid var(--color-primary);
  outline-offset: -2px;
}
```

## 3. Cambios en `PartyList.vue`

Dado que `PartyList.vue` ya usa `@click-item="navigateToDetail"`, no requiere cambios lógicos profundos, solo asegurarse de que los botones de acción dentro de la fila (como el de eliminar o cambiar estado) usen `@click.stop` (que ya lo hacen) para no interferir con la navegación de la fila.

## 4. Próximos Pasos

1. Implementar la lógica de `selectedIndex` en `BaseCatalog.vue`.
2. Añadir la función `scrollToSelected` para asegurar que la fila seleccionada sea siempre visible.
3. Probar con una lista larga de entidades.

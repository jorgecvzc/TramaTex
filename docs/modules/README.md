# 📚 Resumen de Módulos del Proyecto

---

Este directorio contiene la documentación detallada para cada uno de los Módulos de Negocio (Bounded Contexts) que componen TramaTex.

---

## 🧩 Módulos Principales

-   **[Gestión de Identidad (IAM)](./iam/README.md):** Se encarga de la autenticación y autorización de usuarios, incluyendo la gestión de roles y permisos.
-   **[Gestión de Terceros (Party)](./party/README.md):** Unifica la administración de clientes, proveedores y otros contactos.
-   **[Catálogo de Productos (Product)](./product/README.md):** Gestiona el catálogo de productos, incluyendo un sistema avanzado de variantes y atributos.
-   **[Motor de Precios (Pricing)](./pricing/README.md):** Contiene la lógica para el cálculo dinámico de precios, costes y aplicación de descuentos.
-   **[Ciclo de Ventas (Sales)](./sales/README.md):** Administra el flujo comercial completo, desde presupuestos hasta la facturación.
-   **[Ejecución de Manufactura (MES)](./mes/README.md):** Gestiona las órdenes de producción y su seguimiento en el taller.

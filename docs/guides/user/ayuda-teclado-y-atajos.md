# Guía de Ayuda: Uso del Teclado y Atajos Rápidos

Esta guía está diseñada para que los operarios de TramaTex puedan trabajar con la máxima velocidad y eficiencia sin necesidad de utilizar el ratón.

## 1. Navegación Global

Estos atajos funcionan en cualquier parte de la aplicación:

| Atajo | Acción | Descripción |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | **Búsqueda Global** | Abre el buscador para encontrar rápidamente clientes, productos o pedidos. |
| <kbd>Alt</kbd> + <kbd>H</kbd> | **Inicio** | Vuelve al Panel de Control principal. |
| <kbd>Alt</kbd> + <kbd>N</kbd> | **Nuevo** | Crea una nueva entidad o documento (según el módulo actual). |
| <kbd>Esc</kbd> | **Cerrar / Cancelar** | Cierra el modal activo o cancela la edición actual. |

## 2. Manejo de Listados (Tablas)

En pantallas con listas de datos (ej: Clientes, Productos, Pedidos):

- **<kbd>↑</kbd> <kbd>↓</kbd> (Flechas Arriba/Abajo)**: Navega entre las filas de la tabla. La fila seleccionada se resaltará con un borde dorado.
- **<kbd>Enter</kbd>**: Abre el detalle o la ficha de la fila seleccionada.
- **<kbd>Alt</kbd> + <kbd>R</kbd>**: Actualiza los datos de la lista.

## 3. Edición de Pedidos y Líneas de Documento

En la creación de presupuestos, pedidos o albaranes, la gestión de líneas está optimizada para el teclado:

### Navegación entre campos
- **<kbd>Tab</kbd>**: Salta al siguiente campo de la línea (Producto → Cantidad → Precio).
- **<kbd>Enter</kbd>**: Confirma la línea actual y crea una nueva línea vacía debajo.
- **<kbd>←</kbd> <kbd>→</kbd> (Flechas Izquierda/Derecha)**: Se mueve entre las columnas de la línea seleccionada.

### Gestión de cantidades
- **<kbd>+</kbd>**: Incrementa en 1 la cantidad del producto actual.
- **<kbd>-</kbd>**: Decrementa en 1 la cantidad del producto actual.

### Acciones de Línea
- **<kbd>Supr</kbd> / <kbd>Backspace</kbd>**: Elimina la línea seleccionada.

## 4. Formularios y Confirmación

- **<kbd>Ctrl</kbd> + <kbd>Enter</kbd>**: Guarda el formulario completo o confirma la operación principal.
- **<kbd>Shift</kbd> + <kbd>Tab</kbd>**: Vuelve al campo anterior del formulario.

---

*Consejo: Busca las etiquetas pequeñas en gris (ej: <kbd>Alt+N</kbd>) junto a los botones; te indicarán qué tecla rápida puedes usar para esa acción.*

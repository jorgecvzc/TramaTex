## 🎯 Contexto
Para asegurar la entrega de valor incremental en el MVP, se establece un cronograma de alto nivel que organiza los módulos definidos en el [ADR-007](./adr-007-module-implementation-order.md) en fases lógicas con hitos claros.

---

## ✅ Decisión Adoptada
Se establece el siguiente plan de desarrollo, reflejando el estado actual a la finalización del Sprint 18:

### Fases del Proyecto

**Fase 0: Fundaciones Técnicas**
*   **Estado:** ✅ Completada
*   **Hito:** Infraestructura Docker y Módulo `IAM` operativos.

**Fase 1: Dominio Base y Lógica de Negocio**
*   **Estado:** ✅ Completada
*   **Hito:** Gestión de `Party`, `Product` y Motor de `Pricing` con precisión decimal.

**Fase 2: Flujo Comercial**
*   **Estado:** ✅ Completada
*   **Hito:** Módulo `Sales` funcional (Presupuestos, Pedidos, Albaranes y Facturas).

**Fase 3: Operaciones de Taller (MVP)**
*   **Estado:** ✅ Completada
*   **Hito:** Módulo `MES` integrado con ventas y terminales de taller operativos.

## Decisiones Tomadas

### Decisión 1: Estructura por Módulos de Dominio
**Contexto:** Cómo organizar el código base  
**Opciones:** 
- Estructura plana por tipo de archivo
- Estructura por capas técnicas
- Estructura por módulos de dominio (ELEGIDA)
- Monorepo con workspaces

**Decisión:** Estructura por módulos de dominio (ADR-009)  
**Razón:** 
- Refleja dominios de negocio (Party, Product, Pricing, Sales, MES)
- Soporta Clean Architecture con capas separadas
- Permite extraer módulos a servicios futuros sin refactoring masivo
- Facilita TDD y navegación por módulo completo

### Decisión 2: Versionado de Documentación
**Contexto:** Cómo mantener ADRs y documentación sincronizada  
**Decisión:** Versionar en Git junto con código  
**Razón:** Mantener trazabilidad total entre decisiones técnicas y implementación

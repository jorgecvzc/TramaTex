## 4. Notas de trabajo
- TramaTex se concibe como un sistema ERP/MES para microempresa dedicada a EPIs y vestuario personalizable.  
- Objetivo principal: controlar ciclo completo de pedidos estándar y personalizados, integrando ventas, tarificación, inventario y producción.  
- Dominio principal identificado: Ventas + Tarificación.  
- Subdominio especializado: MES para pedidos personalizados.  
- Módulos transversales previstos: Seguridad, Auditoría, Gestión Documental, i18n.  
- Se propone enfoque **local-first**: el sistema debe operar en hardware limitado sin depender de cloud.  
- Stack tecnológico preliminar: Go (backend), Vue 3 + Tailwind CSS (frontend), PostgreSQL, Docker Compose.  
- Se plantea arquitectura **monolito modular** por simplicidad y facilidad de mantenimiento, dejando abierta la evolución futura hacia microservicios.  
- Flujo de negocio preliminar:  
  - Pedidos estándar → flujo comercial → stock → entrega  
  - Pedidos personalizados → flujo comercial + MES → entrega  
- Consideraciones iniciales de mantenimiento y evolución: modularidad, separación de dominios, adaptación a posibles integraciones futuras (maquinaria, SaaS).  
- Documentación de requisitos, casos de uso y trazabilidad conceptual iniciada, pero sin formalización de ADRs.
